# Solana Memecoin Radar

**Outil d'analyse gratuit pour repérer les bundles, les clusters de wallets liés et les wallets de dev sur les memecoins Solana et pump.fun. Analyse uniquement, jamais d'achat.**

## Les trois bots

- **Analyse Pump.fun** : analyse le contrat d'un memecoin et donne un verdict de risque.
- **Veille Tendances X** : vérifie si le token est porté par une vraie communauté sur X.
- **Radar Trenches** : surveille des traders sur X et repère les nouveaux appels.

## Avertissement

Ce n'est pas un conseil financier. Aucune recommandation d'achat, de vente ou de conservation d'un token. Aucun trade n'est exécuté.
